# Todo Tool

[![build](https://img.shields.io/badge/build-passing-brightgreen)](https://github.com/sample-owner/todo-tool/actions)

小さなTodo管理ツールです。ブラウザで動きます。

作者: sample-owner（[GitHub](https://github.com/sample-owner)）

## 使い方

1. `npm install`
2. `npm run dev`
3. http://localhost:3000 を開く

課題の報告は https://github.com/sample-owner/todo-tool/issues へ。
